# Archived milestone documents

These are historical milestone files (`M*`, `U*`, `R*`, `H*`, `L*`, `F*`, `T*`,
`X*`, and `B1-*`), the two milestone screenshots, `screenshots-r9/`, and
`revamp/R11-plan.md`. They were moved here from the top level of `docs/` with
`git mv` so `git log --follow` still works.

They are **historical context only**. They are not current release notes, QA
dashboards, visual specifications, or distribution status. For present
behavior use the current source, the [documentation index](../README.md), and
the [ADRs](../adr/README.md).

Five of these files were still referenced from source comments or scripts
(`L1-fix.md`, `L1-live-dogfood.md`, `M0-foundation.md`, `R10-pocket-parity-ii.md`,
`U4-dogfood.md`). Their old `docs/<name>.md` paths remain as one-line redirect
stubs pointing here so those references, and any external links to them, keep
resolving. The other files had no inbound reference by filename and have no
stub.
